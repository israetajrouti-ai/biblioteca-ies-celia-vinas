## » Descripción General

Este proyecto nace como una práctica para desarrollar una pequeña aplicación web relacionada con la **biblioteca del IES Celia Viñas**.

La idea principal es crear una página donde la información de los libros pueda mostrarse de una manera ordenada y fácil de consultar. De esta forma, el usuario puede navegar por el contenido sin que la página resulte complicada.

El proyecto está pensado principalmente para:

- • Consultar información sobre los libros.
- • Encontrar contenido de una forma sencilla.
- • Facilitar el acceso al catálogo al alumnado.
- • Servir como apoyo para el uso de la biblioteca.

Además, el proyecto permite poner en práctica los conocimientos aprendidos durante el módulo de **Lenguajes de Marcas**, especialmente en HTML y CSS.

> **Objetivo del proyecto:** crear una interfaz sencilla, clara y agradable para representar la información de una biblioteca mediante tecnologías web.

## » Características Principales

Entre las características principales del proyecto se encuentran:

- **Catálogo de libros** → la información se presenta de manera estructurada.
- **Consulta del contenido** → permite al usuario navegar por la información disponible.
- **Diseño visual** → se utilizan diferentes estilos para conseguir una interfaz más clara.
- **Adaptación a diferentes pantallas** → el diseño está pensado para distintos dispositivos.
- **Navegación sencilla** → se mantiene una estructura fácil de entender.
- **Contenido organizado** → los diferentes elementos están separados para facilitar su lectura.
- **Tecnologías web** → el proyecto utiliza principalmente HTML5 y CSS3.

## » Tecnologías Utilizadas

Para realizar el proyecto se han utilizado principalmente tecnologías básicas del desarrollo web.

### HTML5

**HTML5** se utiliza para crear la estructura de la página y organizar el contenido mediante elementos como encabezados, párrafos, listas, imágenes y enlaces.

### CSS3

**CSS3** se utiliza para darle estilo a la página. Gracias a CSS se pueden controlar aspectos como los colores, tamaños, espacios y distribución de los elementos.

También se utilizan recursos como:

- **Flexbox** → para organizar elementos.
- **CSS Grid** → para crear estructuras de varias columnas.
- **Media Queries** → para adaptar el diseño a diferentes tamaños de pantalla.

### JavaScript

El proyecto dispone de una carpeta para JavaScript, donde se pueden añadir funcionalidades e interacciones para mejorar la experiencia del usuario.

### Herramientas utilizadas

- **Visual Studio Code** → editor utilizado para desarrollar el proyecto.
- **Git** → herramienta para controlar las versiones del proyecto.
- **GitHub** → plataforma utilizada para almacenar y compartir el código.
- **Navegadores web** → utilizados para comprobar el funcionamiento de la aplicación.

Para trabajar con este proyecto no se necesitan demasiadas herramientas.

1. Un ordenador con Windows, Linux o macOS.
2. Un navegador web actualizado.

## » Instalación y Despliegue

### 1. Clonar el repositorio

Si el proyecto está disponible en GitHub, se puede descargar utilizando:

```bash
git clone https://github.com/israetajrouti-ai/gestor-biblioteca.git
```

### 2. Entrar en la carpeta del proyecto

```bash
cd "mi proyecto"
```

### 3. Abrir el proyecto con Visual Studio Code

```bash
code .
```

También se puede abrir la carpeta manualmente desde Visual Studio Code.

### 4. Abrir la aplicación

Para visualizar la aplicación se puede abrir directamente el archivo:

```text
index.html
```

Otra opción es utilizar la extensión **Live Server** de Visual Studio Code.

Para ello:

1. Abrir `index.html`.
2. Hacer clic derecho sobre el archivo.
3. Seleccionar **Open with Live Server**.
4. La aplicación se abrirá automáticamente en el navegador.

## » Estructura del Proyecto

Actualmente, la estructura principal del proyecto es la siguiente:

```text
mi proyecto/
│
├── assets/
│   └── images/
│
├── css/
│   └── styles.css
│
├── index.html
└── README.md
```

### Descripción de los archivos

| Archivo o carpeta | Función |
|---|---|
| `index.html` | Página principal de la aplicación. |
| `css/` | Contiene los archivos relacionados con los estilos. |
| `styles.css` | Hoja de estilos principal del proyecto. |
| `assets/` | Carpeta destinada a los recursos utilizados por la aplicación. |
| `images/` | Carpeta destinada a las imágenes del proyecto. |
| `README.md` | Documento donde se explica y documenta el proyecto. |

La estructura se ha mantenido sencilla para que sea fácil localizar cada archivo.
